## LinkedIn

Post: `05-li-portrait-light.png` (single image, 1080 × 1350).
Why it’s built this way: the first two lines are the hook before “see more”. No link in the post, because LinkedIn holds back reach on posts with links, so the link goes in the first comment. It closes on a question because comments carry more weight than likes. Three hashtags, no more.

```
60 seconds to write a prompt. Then I’m not allowed to touch it.

That’s the rule for the next 30 days. One poster a day, made in Claude Code from whatever I can type in a minute. Claude can ask me questions and I can answer them. That’s it. No redos, no tweaks, no quietly fixing the kerning at midnight.

Whatever comes back gets posted. Right, wrong or hideous.

Day 01 is a clock with all sixty seconds and no hands. Fair.

Most AI work you see has had someone polishing it for hours before it goes out. That’s the job, and I’d do the same for a client. But I want to see what the system does when the only input is a rushed brief. That’s closer to a Monday morning than any demo.

Every prompt goes on a wall, free to copy. Link in the comments.

What would you have typed in 60 seconds?

we give a sh*t.

#ClaudeCode #AIDesign #GraphicDesign
```

First comment, posted straight after:

```

```

## Instagram (carousel)

Post, in order: `01-ig-post-light.png`, `02-ig-post-light.png`, `03-ig-post-light.png` (1080 × 1440).
Why it’s built this way: the poster leads, because the first frame is all the feed shows. Frame 2 makes people swipe for the rules. Frame 3 sends them to the bio. The caption asks for a save, because saves count for more than likes. Hashtags are niche, not huge, so the post can actually rank in them.

```
Day 01 of 30. No hands.

60 seconds to prompt Claude Code, then hands off. It asks, I answer, it makes, I post. No redos.

Today it gave me a clock with no hands. Bit on the nose. Fair though.
```
