# Thirty posters

30 days. 30 posters. Each one made in Claude Code from a prompt written in 60 seconds, then posted as is.

Open `index.html` to see the wall. Every poster has its prompt on it, free to copy.

- `days/NN/`: the prompt, the poster, the socials and the post copy for each day
- `scripts/build-day.sh NN`: renders a day and updates the wall
- `system/`: the Blame Opal template kit used for the social posts
